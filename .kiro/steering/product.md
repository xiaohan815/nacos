# Nacos 产品概述

Nacos（Dynamic **Na**ming and **Co**nfiguration **S**ervice）是一个易于使用的平台，专为云原生应用和微服务架构设计，提供动态服务发现、配置管理和服务管理功能。

## 核心功能

- **服务发现与健康检查**：基于 DNS 或 HTTP 的服务注册与发现，提供实时健康监控
- **动态配置管理**：跨所有环境的集中式配置管理，配置更新无需重新部署应用
- **动态 DNS 服务**：支持权重路由，便于实现中间层负载均衡和灵活的路由策略
- **服务与元数据管理**：提供控制台管理服务、配置、Kubernetes DNS、健康指标和统计信息

## 支持的集成

- Dubbo/gRPC 服务
- Spring Cloud RESTful 服务
- Kubernetes 服务
